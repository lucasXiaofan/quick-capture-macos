# Changelog

## Unreleased

### Fixed
- **New Ticket window no longer clips its buttons.** The text, attachments, attach buttons and tag hints sit in one bordered box; Save / Append / Send have a row of their own that never shrinks, down to the window's minimum width.
- **Tickets respect per-send agent choices:** the compose toast names the selected agent; queued runs freeze defaults at send time, and replies sent during a run preserve their model for the next turn. App rebuilds always ask for confirmation and require no running or queued tickets, rather than stopping active agents. See [workflow and architecture](docs/tickets-workflow.zh-CN.md).
- **Closing Brake or AI Chat no longer hides the selfie camera** (or any other Quick Capture window) during a screen + camera recording. Both used to hand focus back with `NSApp.hide`, which hid every window of the app while the camera kept recording; they now re-activate the app you came from instead (`AppWindows`).
- **EPUB highlights in Brake are visible in Dark Mode.** They were saved but painted transparent by the dark-mode style reset. Recolouring and removing an EPUB highlight work again, and the same passage isn't saved twice.

### Changed
- **Media Capture "Smart" compression no longer blurs the background** of camera videos: it now drops them to 15 fps at 720p HEVC, like screen recordings (same ~4 MB/min, every frame gets more bits and nothing is cut out). `video_notes.compression` values are unchanged.
- **Resize the camera square visually:** Settings → Media Capture → Screen + camera has a preview of the recording frame; drag the camera square to another corner or its handle to resize it (saved to `video_notes.screen_camera_size` / `screen_camera_corner`), and **Show my camera** shows you in it.
- **Brake and AI Chat are ordinary windows:** normal window level, on the Space they opened in (not every Space, not above full-screen apps), and Quick Capture appears in the Dock and ⌘-Tab while one is open.
- **The app is now just "Quick Capture"** (it works with Obsidian but doesn't depend on it). The bundle identifier is unchanged, so permissions carry over. Settings move automatically from `~/Library/Application Support/Obsidian Quick Capture` to `~/Library/Application Support/Quick Capture` on first launch, and the installer removes the old `Obsidian Quick Capture.app`.

### Added
- **Tickets: designs.** Library → Designs holds canvases — cards, groups, images, labelled arrows — that you edit like an Obsidian canvas (double-click to add or edit, drag a card's edge dot to connect, drag, resize, colour, ⌫, ⌘Z; pan and zoom). Stored as JSON Canvas in `<ticket folder>/designs/*.canvas`, so they open in Obsidian too. **Import a folder…** copies an existing folder of `.canvas` files and their images in without touching the originals. The agent reads them and draws or redraws one with `save_design`. Two designs are generated from the live rules and cannot go stale: *How the ticket system works* (your input → what the agent is told → its action space → files → views) and *How a capture is categorized* (kind → project → tags → status, with every kind, rule and view).
- **Tickets: the agent has named tools.** Beyond the ticket it is answering it can `create_ticket`, `update_ticket`, `merge_tickets`, `set_principle`, `update_project`, `define_tag`, `merge_tags`, `delete_tag`, `add_kind` and `save_design` (an `actions` list in its reply). Each use, and each refusal with its reason, is in the decision log; Agent → Tools lists them.
- **Tickets: notifications.** A banner when the agent has answered and a ticket waits for you, and a reminder for every open ticket with a deadline: 7:00 on the due day, or 5 hours before when the deadline has a time (new optional **due time** next to Due; the agent sets `due_time`). Clicking one opens the ticket. Settings → Tickets → Notifications; `tickets.notify_your_turn`, `notify_due`, `due_notify_hour`, `due_lead_hours`.
- **Tickets: tags live in a `tags/` folder as a layered vocabulary** (built on the skill-flywheel `tags` skill): `tags/SKILL.md` holds the rules, `references/index.md` the depth 1–2 tags (max 30), deeper tags go in `references/<l1>/<l2>.md`, and an optional `references/map.md` tells the agent how to classify. A tag is a path (`career/build`) on one line, ``- `tag`: meaning. Action: …``. The Tags page shows the tree and the loose tags; merging moves sub-tags with their parent. Tags that an earlier build kept in `structure.json` move over on first launch.
- **Tickets: project page at a glance.** Three cards on top — where it stands, what needs attention, what happened recently — then the plan as rows, and the context as one foldable card per heading instead of one block of text.
- **Tickets: tags carry a meaning and an action.** A new **Tags** page lists every tag with its meaning, action and ticket count; edit in place, merge one into another, delete everywhere, or ask the agent to tidy up. The agent may only use registered tags and must state a meaning and an action to add one; tags you type yourself are kept and flagged until defined. Tags are chips on the ticket and in the inbox.
- **Tickets: Projects page grouped by category**, each card showing the three open tickets most worth a look (due soonest, then waiting for you), each clickable. A project's category is free text (research, class, personal, or your own).
- **Tickets: resizable columns.** Drag the edge of the sidebar or the ticket list; double-click resets; widths are remembered.
- **Tickets plugin** (off by default; ⌃⌥E new ticket, ⌃⌥⇧E window): capture anything as a ticket — todo, question, idea, habit check-in, bug, meeting note, resource — with text, screenshots and files. Claude Code, Codex or Pi classifies it (kind, project, tags, dates), takes the first turn and you reply like email; status is New / Agent's turn / Your turn / Closed. Views built from the flat tickets: an email-style inbox, projects with used days and a ship-it nudge, habit heatmaps, a Gantt plan with todos by deadline, a library of principles and resources. The agent's instructions, per-kind rules, decision log and your corrections (fed back into every prompt) are all in the window; it can merge related tickets without touching the originals. Access scope in Settings: read only, workspace (sandboxed commands in chosen folders) or full. Tickets are Markdown files in a folder you choose. **Self-update:** the ticket agent can change Quick Capture's own source and order a rebuild + restart (`tickets.self_update`, off by default). Every run is snapshotted into git first (uncommitted work included, nothing touched), the installed app is backed up, a failed build leaves the app alone, and a new version that doesn't report healthy is replaced by the old app and source automatically; any update can be rolled back from Agent → App updates. Pick the agent, model and effort (Claude Code `--effort`, Codex reasoning effort, Pi thinking) per agent in Settings, or for a single reply in the reply box. Settings: `tickets.folder`, `agent`, `claude_model`, `codex_model`, `pi_model`, `claude_effort`, `codex_effort`, `pi_effort`, `auto_process`, `access`, `working_directory`, `extra_folders`, `allow_network`, `timeout_minutes`. See [docs/tickets.md](docs/tickets.md).
- **Brake plugin** (off by default, no default shortcut): one shortcut or wheel slice shows a single reminder you set up in advance, to pull yourself back on the brink — a PDF or EPUB book opened at a set page, a video or audio clip from a set second, an image, or a line of text (shown above the file or on its own). Opens fresh at the bookmark every time, over full-screen apps; books read like Apple Books (paper backdrop, two-page spread when wide, red ribbon on the bookmarked page, ← → / swipe to turn, scrubber, ⌘D bookmarks); EPUB text re-flows in your choice of font and size, PDFs zoom (⌘+ / ⌘− / pinch); select text to highlight in five colours (saved into the PDF; beside the config for EPUB); Settings picks the bookmark from page previews (PDF) or the table of contents with a text preview (EPUB); **Start Here Next Time** saves a video/audio position; Esc closes. Settings: `brake.path`, `page`, `chapter`, `chapter_progress`, `font`, `font_size`, `pdf_zoom`, `start_seconds`, `text`, `autoplay`. See [docs/brake.md](docs/brake.md).
- **Storage Manager plugin** (off by default, no default shortcut): a native rewrite of the standalone storage-dashboard script. Free space, then everything that can be reclaimed, biggest first, with age: tool caches, app caches, `node_modules` and virtualenvs found in your project folders, conda environments, LM Studio / Hugging Face / Whisper models, device backups. Caches are emptied; everything else goes to the Trash. A folder Explore tab, Empty Trash, optional Mole preview, protected folders. Nothing is hardcoded to one Mac: folders are discovered at runtime. See [docs/storage-manager.md](docs/storage-manager.md).
- **Memory Monitor plugin** (off by default, no default shortcut): a live memory window with a used / cached-files chart (cached files hold mmap'd model weights that Activity Monitor hides), a baseline to measure what loading a model costs, apps with their full footprint and Quit / Keep / Quit All Not Kept, and big non-app processes with Stop. See [docs/memory-monitor.md](docs/memory-monitor.md).
- **Read Aloud reading panel:** a floating panel shows the recognized text with the spoken part highlighted, a progress bar with time, Pause / Resume, Stop and Replay, and the status or error (no text, no Python, engine stopped) that used to be a toast or nothing. New *Pause / Resume Reading* action. The engine now reports the text of each chunk (`start` event).
- **Read Aloud plugin** (off by default, no default shortcuts): drag a region of the screen and hear its text in a local Kokoro-82M voice (MLX, Apple Silicon); *Read Clipboard Aloud* and *Stop Reading* too. Text by Apple Vision (on-device); speech by `Resources/read_aloud/kokoro_server.py`, a Python process that starts on the shortcut (the model loads while you select), first audio ≈0.8 s when warm (measured in Low Power Mode), and exits after `read_aloud.idle_minutes`. Memory: MLX limit + capped buffer cache, and the engine exits if it passes `read_aloud.memory_limit_gb` (default 3). Model and saved audio live in `~/Library/Application Support/Quick Capture/read_aloud/` (`models/`, `audio/`, pruned above `read_aloud.audio_limit_mb`), with sizes and Delete buttons in Settings. Settings: `python_path`, `voice`, `speed`. See [docs/read-aloud.md](docs/read-aloud.md).
- **Task Log plugin** (off by default, no default shortcuts): a screenshot or a note appended to a plain daily file `<folder>/YYYY-MM-DD.md` (`**HH:mm** text`, images in `<folder>/images/`), no Obsidian needed. Made for an agent that turns the log into task updates (skill-flywheel's project-manager). Settings: `task_log.folder`. See [docs/task-log.md](docs/task-log.md).
- **One Stop shortcut for all Media Capture recordings:** ⌃⌥S stops a video, a screen + camera recording or meeting audio alike, and ⌃⌥P / ⌃⌥X pause and discard any of them. The separate *Stop Meeting Recording* shortcut (⌃⌥⇧A, `meeting_stop`) is gone; a leftover entry in `config.json` is ignored.
- **Balance the Mac's sound and your voice in screen + camera recordings:** Settings → Media Capture → Screen + camera → **Mac sound** and **Your voice** (0–300%, defaults 70% / 100%; `video_notes.screen_system_volume`, `video_notes.screen_mic_volume`). Applied when the two tracks are mixed at stop, with a soft limiter above 100%. Previously both were mixed at 100%, so the Mac's sound drowned out the voice.
- **Radial Wheel plugin** (off by default, ⌃⌥W): one shortcut for all features. A game-style wheel of 2–12 actions from any plugin opens at the pointer; hold the shortcut, point toward a slice and let go — or tap it, then click a slice or press 1–9 / 0. Slices, their order and the wheel size are set in Settings → Radial Wheel (`radial_wheel.slots`, `radial_wheel.size`). See [docs/radial-wheel.md](docs/radial-wheel.md).
- **Esc stops any Media Capture recording:** while a video, screen or meeting recording runs, Esc pauses it and asks Save / Discard / Keep going (`video_notes` hotkey `stop_prompt`). Meeting recordings can now be discarded too. Esc is only grabbed while something records. Shortcuts accept `<esc>`.
- **`QC_SNAPSHOT_DIR` for development:** start the app with it set and post the distributed notification `QuickCaptureSnapshot` to save each of its windows as a PNG (no Screen Recording permission needed). See [docs/development.md](docs/development.md).
- **Rank tags in the Media Capture dashboard:** a **Tag Order** panel at the left of the dashboard (open by default, shown or hidden only from the header button) lists the tags in column order with rank numbers and counts; ↑ / ↓ on a row moves a tag and the board follows immediately. Columns show the same rank and have ‹ › in their header to move left / right; right-click or ⋯ for top / bottom. **Sort by Most Used**, and Untagged can be the last column (`video_notes.untagged_last`). Replaces dragging column headers, which didn't work inside the horizontally scrolling board.
- **Video Notes is now Media Capture**, with a dashboard of three tabs: **Videos**, **Selfies** and **Recordings**, sharing one set of tags. A recording's card holds the audio and its transcript together (Play, Transcript, the first lines or the lines matching the search; search covers transcripts). Selfies open in Preview. Selfies and meeting recordings ask for an optional tag and note like videos do (`video_notes.selfie_prompt`, `video_notes.meeting_prompt`). The config key stays `video_notes`, so settings and folders carry over. See [docs/media-capture.md](docs/media-capture.md#dashboard).
- **Media Capture selfie** (⌃⌥F): the first press shows the camera, the second (or Space) takes the photo. Saved as JPEG in `quick-capture-selfie`, mirrored like the preview (`video_notes.selfie_mirror`). See [docs/media-capture.md](docs/media-capture.md#selfie).
- **Media Capture meeting audio** (⌃⌥A starts, press again to pause / resume, ⌃⌥S stops): records the microphone and the Mac's own sound (ScreenCaptureKit; needs Screen Recording) for as long as a meeting lasts. Written to a fragmented file while recording, so a crash or quit keeps everything up to the last ~10 s (finished on next launch). On stop it's mixed into one `.m4a` (default HE-AAC mono 32 kbps, ~16 MB/hour; `video_notes.meeting_compression`), then transcribed on this Mac into a `.txt` next to it — only after the recording, never live. Engines: whisper.cpp (uses Handy's downloaded models), OpenAI Whisper, or Apple's `SpeechTranscriber` on macOS 26; Whisper handles Chinese and English mixed. A small REC timer stays out of screen sharing. See [docs/media-capture.md](docs/media-capture.md#meeting-audio).
- **Smaller Media Capture, measured:** camera videos compress to 720p HEVC (~4 MB/min instead of ~17), screen + camera videos to 15 fps HEVC (~4–6.5 MB/min instead of ~22; text stays sharp), and audio to AAC 64 kbit/s mono / 96 kbit/s stereo. Screen recordings are now compressed too. **⋯ → Compress All Videos** and **Compress Again** bring older videos to the new targets (`compression_version` in `index.json`). Measurements and the options compared: [docs/video-compression.md](docs/video-compression.md).
- **Discard a bad take in Media Capture:** ⌃⌥X while recording pauses, asks, then throws the recording away (or resumes). The tag prompt after a recording has **Discard…** (⌘⌫) too. Discarded videos go to the Trash.
- **Media Capture screen + camera recording** (⌃⌥⇧R; press again to pause, ⌃⌥S stops): records the main display at 720p (H.264) with your camera as a rounded square in a corner, the Mac's sound and the microphone, mixed into one audio track. The square's size (10–50% of the height) and corner are set in Settings (`video_notes.screen_camera_size`, `video_notes.screen_camera_corner`). The preview sits where the square will be; the app's own windows aren't recorded. Same tag-and-note prompt afterwards; compressed in the background to 15 fps HEVC. Needs Screen Recording permission. Built on ScreenCaptureKit; see [docs/media-capture.md](docs/media-capture.md#screen--camera).
- **Media Capture volume boost:** play every video up to 800% louder without changing the Mac's volume (Settings or the dashboard header; `video_notes.volume`). Uses an audio tap with a soft limiter; files are untouched.
- **Redesigned Video dashboard:** thumbnails with length, a Quick Play strip (drop a card on a slot to assign it), search, Record/Stop and volume in the header, empty state. Settings → Media Capture now opens with the dashboard.
- **Menu bar menu is now a short launcher built from the plugins:** the top shows each enabled plugin's most important action (`Plugin.primaryActions()`, seven rows at most), alerts such as Unsaved Captures (`menuAlerts()`), and **Plugins ▸** holds one submenu per plugin with its other actions, extra items and a direct link to its Settings page. Switching a plugin off removes it from the menu. Actions can be hidden from the menu (`showsInMenu`), e.g. Media Capture' per-slot play, or Pause/Stop while not recording. Plugins can also put sections at the top of their Settings page (`overviewView`).
- **Skill Manager plugin** (off by default, ⌃⌥K): a dashboard of every Claude Code / Codex skill (`~/.claude/skills`, `~/.codex/skills`, `~/.agents/skills`, plus folders you add). Overview cards, search, every file of a skill rendered as Markdown with syntax highlighting, file paths in the text open the file, plain-text editing with ⌘S, and **New skill** from a template. Built-in skills hidden by default. The UI is a web page (`Resources/skill_manager/`) sharing AI Chat's renderer. See [docs/skill-manager.md](docs/skill-manager.md).
- **Media Capture plugin** (off by default): ⌃⌥R records the camera (press again to pause), ⌃⌥P pauses, ⌃⌥S stops, with a small live preview at the bottom of the screen. After stopping, pick an existing tag or type a new one and add a note. A Kanban dashboard shows one column per tag, newest first; drag cards between columns to retag, double-click to play in the default player, right-click for quick-play slots, Trash and more. ⌃⌥V then 1–5 plays the video in that slot. Shows each column's and the library's disk usage. Tags: new tags appear next to Untagged, the **Tag Order** panel ranks them, adds and deletes them (always with confirmation; videos move to Untagged), and there are no built-in tags. Quick play opens a small player that starts automatically after half a second, with optional direct shortcuts per slot. Videos are compressed in the background (Smart: sharp person, blurred background, HEVC; audio untouched), see [docs/video-compression.md](docs/video-compression.md). See [docs/media-capture.md](docs/media-capture.md). Declares microphone access (`NSMicrophoneUsageDescription`, audio-input entitlement).
- **Nose Control panels:** the screen is split into three big panels; pressing **1**, **2** or **3** jumps the pointer to the middle of that panel and the nose then moves it inside the panel. Columns or rows; a **Whole Screen** shortcut leaves the panel. Plain keys are released while paused. Dividers and numbers on screen show where each key jumps, and panels follow the display the pointer is on (not always the primary one).
- **Plain-key shortcuts** for actions that are only active temporarily (`PluginAction.allowsBareKey`). Nose Control's click, panel, pause and sensitivity shortcuts can now be any key. Clearer click labels and an on-screen cheat sheet of the shortcuts while tracking.
- **Shortcuts page** in Settings: every shortcut of every plugin in one place, with duplicate detection. Recording a shortcut another action already uses asks whether to replace it, and ⌘-only combinations get a heads-up that they overlap with other apps' commands.
- **Open Settings shortcut** (default ⌃⌥,): a configurable system-wide shortcut. The menu item no longer uses a fixed ⌘, that clashed with other apps.
- **Nose Control plugin** (off by default, ⌃⌥N): move the pointer by turning your head, tracked on-device with the camera, and click with configurable keyboard shortcuts (left, right, double click, pause, sensitivity up/down, recalibrate). Live feedback during calibration, separate horizontal/vertical sensitivity, and a steadiness setting. See [docs/nose-control.md](docs/nose-control.md). **Experimental:** eye and nose tracking were both tried and found too unstable to replace a mouse, so Keyboard Mouse is the recommended way to move the pointer without one.
- **Keyboard Mouse plugin** (off by default): hold Right Option (configurable) and use WASD to move the pointer with acceleration, 1–6 to jump to one of six screen panels, Space for the left button (press twice for a double click, hold to drag) and E for the right button. See [docs/keyboard-mouse.md](docs/keyboard-mouse.md).
- Plugins can hide a shortcut while it isn't relevant (`Plugin.isAvailable`), so it isn't grabbed system-wide.
- The app declares camera access (`NSCameraUsageDescription` and the camera entitlement in `scripts/entitlements.plist`).

## 3.0.1 — 2026-09-28

### Fixed
- **“Capture not saved” when it actually was saved:** Obsidian's CLI sometimes drops a command's reply after running it. The app now retries calls with a missing reply (the bridge never saves twice), and logs lost replies to `obsidian_capture/bridge.log`. See [Troubleshooting](docs/troubleshooting.md#capture-not-saved--obsidian-cli-isnt-responding-but-the-capture-was-saved-fixed-in-301).

## 3.0.0 — 2026-09-28

### Added
- **AI Chat plugin** (⌃⌥Space): a quick, temporary chat with Claude Code or Codex. It detects installed CLIs automatically. Models: Claude Sonnet (default), Opus, Fable, Haiku; Codex GPT-6 Luna plus your account's models. It can search the web, edit files, and run sandboxed commands in a chosen working folder, with Read only / Edit / Full access permission modes. Renders Markdown, LaTeX, tables, and highlighted code offline. Web links and file links (`path:line`) are clickable, and files dropped on the window are referenced in the message.
- **Plugin architecture:** every feature is a plugin with its own on/off switch, shortcuts, menu items, Settings page, and options in `config.json`. See [the plugin guide](.claude/skills/new-plugin/SKILL.md).
- New Settings window: a sidebar with General plus one page per plugin. Shortcuts can be removed as well as changed.
- Onboarding lists each plugin with its setup steps.
- Standard Edit shortcuts (⌘C/⌘V/⌘A/⌘Z) now work in the app's text fields.
- Tests for the chat renderer and a real-CLI smoke test (`scripts/chat-smoke.sh`).

### Changed
- `config.json` groups settings under `plugins.<id>` and writes out every option. Version 2 files are migrated automatically, keeping your shortcuts and vault.
- Command-line tools are found through your login shell's `PATH` and common install locations, so the app works the same on any Mac.
- The Obsidian CLI is found wherever Obsidian is installed. Obsidian Capture starts switched on only if Obsidian is installed.
- The bundle ID can be set with `BUNDLE_ID=…` when building.

### Fixed
- **Building froze Obsidian** when the project was inside a vault: the DMG staging folder contained a symlink to `/Applications`, which Obsidian tried to index. Staging now happens in a temp folder. See [Troubleshooting](docs/troubleshooting.md#obsidian-froze-after-building-the-app-fixed-in-300).

## 2.0.0 — 2026-09-26

- Rewrote the Python version as a native Swift/AppKit menu-bar app. No Python runtime, and no Accessibility permission for shortcuts.

- Welcome window with live setup status, a Settings window with a shortcut recorder, a Login Item, a watched `config.json`, and a recovery folder for unsaved captures.
